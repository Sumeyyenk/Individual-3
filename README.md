# C# Object-Oriented Programming Fundamentals

A lightweight console project demonstrating core OOP principles in C#, including method overloading, class inheritance, and dynamic parameter handling.

### Features
* Calculator: Demonstrates method overloading across different data types (int, double, string) and argument counts, with basic divide-by-zero validation.
* Animal Hierarchy: Demonstrates inheritance and behavioral specialization through base and derived classes (`Cat`, `Dog`).
